# Litoral Imágenes · publicaciones de Instagram

Repositorio de trabajo de BC Informática para @litoralimagenes.

- `kit/`: dibuja las piezas del tablero «Litoral Lab · Contenidos» (`python3 kit/render.py kit/index.html pieza.json salida/`). Carruseles en JPG 1080×1350 y reels en MP4 1080×1920.
- `instagram/<id-de-pieza>/`: los archivos que se publican. Instagram los toma desde el link público de cada archivo.

Solo se suben piezas aprobadas por el Dr. Matías Carrero. Nunca imágenes ni datos de pacientes.
